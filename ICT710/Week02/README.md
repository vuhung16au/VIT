# Week 02

## Week Overview

Week 02 focuses on understanding the problem space and comparing different interaction types before committing to a single solution.

## Quick Recap From Previous Week

Week 01 introduced IxD basics through a first interactive doctor booking interface.

## Learning Objectives And Outcomes

Students should be able to apply the 5W framework, compare interaction types, and think conceptually before building physical interface details.

## What To Do This Week

Read `demo-plan.md`, review the interaction-type examples, and trace how the booking problem changes across instructing, conversing, manipulating, and exploring.

## Key Deliverable Or Takeaway

A clearer understanding of how the same task can be designed in very different ways.

## Looking Ahead To Next Week

Next week moves into cognitive, social, and emotional UX foundations.
