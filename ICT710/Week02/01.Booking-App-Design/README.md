# Booking App Design

Static HTML design mockup for a doctor booking application, created as part of Week 02 ICT710 coursework.

## Demo

[https://booking-app-design.vercel.app](https://booking-app-design.vercel.app)

## Overview

This project contains design explorations and static HTML prototypes for a doctor booking application. It demonstrates various design approaches and interaction patterns for healthcare appointment booking.

## Contents

- **design.md** - Main design documentation covering problem space, conceptual design, and interaction types
- **alternative-design.md** - Alternative design approaches and variations
- **rationale.md** - Design rationale and decision-making process
- **index.html** - Static HTML prototype

## Running Locally

### Option 1: Simple HTTP Server

```bash
# Using Python 3
python3 -m http.server 4173
```

Then open http://localhost:4173

### Option 2: Using bun

```bash
bun run dev
```

## 🚀 Deploy to Vercel

This static HTML project is deployed to Vercel.

### Quick Deploy

```bash
# From the project directory
vercel --yes

# For production deployment
vercel --prod
```

### Live Demo

Visit the deployed version: [https://booking-app-design.vercel.app](https://booking-app-design.vercel.app)
