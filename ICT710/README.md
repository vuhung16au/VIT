# ICT710

## Course Overview

ICT710 is a hands-on course in Interaction Design (IxD), UI, and UX. The repo is organized week by week so students can move from setup and fundamentals to design systems, evaluation, and usability testing.

## Who This Course Is For

This course is for anyone who wants to learn IxD through practical work. It is especially useful for students who want a balanced path between design thinking and frontend implementation.

## Learning Objectives And Outcomes

By the end of the course, students should be able to understand core IxD concepts, build interactive prototypes, connect theory to implementation, and evaluate interface quality using structured methods.

## Course Highlights

- hands-on weekly demos and mini-projects
- balanced theory and practice
- modern web tooling with Next.js, React, and frontend workflows
- strong focus on interaction quality, not just visual styling

## Course Structure

The course runs from `Week00` to `Week12`.

- `Week00`: setup and first IxD app
- `Week01` to `Week04`: foundations, problem space, UX, and design process
- `Week05` to `Week09`: research, interfaces, personas, requirements, and prototyping
- `Week10` to `Week12`: design systems, evaluation, and usability testing

## How To Use This Repo

Start at `Week00` and move forward in order. In each week:

1. read the week `README.md`
2. check the week `demo-plan.md`
3. review the docs in that folder
4. run or inspect the project for that week

## Tools And Setup

Students should begin with `Week00/Tools.md`, `Week00/Environment-Setup.md`, and `Week00/Troubleshooting.md`. Use `make help`, `make build`, `make clean`, and `make size` at the root or week level to work with the projects.

## Demo Recording

The repo also includes an automated demo-recording workflow for the key week projects in Weeks 01 to 12. See `RECORDING.md` for the shared setup, supported projects, and `make demo` / `npm run demo:record` usage.
