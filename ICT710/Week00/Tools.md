# Week 00 Tools and Frameworks

This document introduces the main tools, frameworks, and languages that students are encouraged to use throughout ICT710.

The course focuses on using these tools to explore and build Interaction Design (IxD), UI, and UX concepts through practical demos and small projects. Most of the implementation work in this course is web-based, with some mobile design principles discussed where relevant.

## Design Tools

Students are encouraged to use one or more of the following design tools for sketching ideas, wireframing, prototyping, and communicating design decisions:

1. Figma
2. MockFlow
3. Canva
4. Lucidchart
5. Visual Paradigm

These tools are especially useful when:

- Creating wireframes and mockups
- Planning user flows
- Comparing design alternatives
- Presenting conceptual models and diagrams

## Coding Tools

Students are encouraged to use the following coding tools during labs, demos, and project work:

1. VS Code
2. Codex
3. Cursor
4. GitHub Copilot

We will primarily use coding tools during demo implementations to help students move from concept to working prototype more quickly.

## Frameworks and Platforms

The course uses a small set of modern frameworks repeatedly across weekly demos:

- Next.js 16 with App Router
  Used for most web application demos in the course.

- React
  Used as the core UI library behind many interactive interfaces.

- Tailwind CSS 4.2
  Used for rapid prototyping, responsive layouts, and modern UI exploration.

- Bootstrap 5.3.3
  Used in some weeks for structured layouts, dashboards, forms, and evaluation tools.

- Vite
  May be used in some lightweight frontend setups or supporting examples, but Next.js is the main framework used across the weekly demo plans.

- Material Design 3 (Google)
  Used as a design system and mobile UI reference when discussing design languages, consistency, and mobile interaction patterns.

## Programming Languages

The main programming languages used in this course are:

- JavaScript
- TypeScript

TypeScript is used heavily in many weekly demos because it helps students define interfaces, data models, and component props more clearly.

## Other Libraries and Tools Used in Some Weeks

Some weekly demos also introduce supporting libraries and tools such as:

- Chart.js
- jsPDF
- Google Fonts

These are not the main focus of Week 00, but students may encounter them in later weeks when building analytics dashboards, export features, design systems, or polished presentations.

## How These Tools Support the Course

Together, these tools and frameworks help students:

- Explore interaction design ideas quickly
- Build prototypes and demo apps efficiently
- Compare UI and UX approaches across different scenarios
- Practice modern frontend workflows
- Connect design decisions with real implementation

## Summary

In this course, students will mainly use:

- Design tools for ideation, wireframing, and prototyping
- Coding tools for demo implementation and experimentation
- Next.js, React, Tailwind CSS, and Bootstrap for web-based interactive systems
- JavaScript and TypeScript for implementation

These tools will support the course goal of understanding and applying IxD, UI, and UX principles through hands-on work.
