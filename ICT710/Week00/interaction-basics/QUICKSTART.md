# Quickstart

## Prerequisites

- Node.js 20+
- npm 10+

## Install

```bash
cd Week00/interaction-basics
npm install
```

## Run Development Server

```bash
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000)

## Build Production Bundle

```bash
npm run build
npm run start
```

## Lint

```bash
npm run lint
```

## Deploy to Vercel

```bash
# First deployment
vercel

# Production deployment
vercel --prod
```

Your app will be live at the URL provided by Vercel (e.g., `https://interaction-basics.vercel.app`).
