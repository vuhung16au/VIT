# Week 00

## Week Overview

Week 00 prepares students for the course by setting up the development environment and building a tiny first IxD app.

## Quick Recap From Previous Week

There is no previous week. This is the starting point for the course.

## Learning Objectives And Outcomes

Students should be able to install the required tools, run a Next.js app, edit it locally, and understand how a small interaction can demonstrate feedback, validation, and confirmation.

## What To Do This Week

Read `Tools.md`, `Environment-Setup.md`, and `Troubleshooting.md`, then work through `demo-plan.md` and the `interaction-basics` app.

## Key Deliverable Or Takeaway

A working local development environment and one very small interactive app that builds successfully.

## Looking Ahead To Next Week

Next week moves into the foundations of Interaction Design and the differences between UI, UX, and IxD.
