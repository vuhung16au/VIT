# Week 06

## Week Overview

Week 06 examines different interface types by implementing multiple ways to complete the same booking task.

## Quick Recap From Previous Week

Week 05 focused on gathering data from users through multiple research methods.

## Learning Objectives And Outcomes

Students should be able to compare CLI, GUI, touch, voice, and gesture-style interfaces and explain when each is appropriate.

## What To Do This Week

Read `demo-plan.md`, try the interface examples, and compare the strengths and weaknesses of each modality in context.

## Key Deliverable Or Takeaway

A clearer sense that interface choice depends on user context, task, and constraints.

## Looking Ahead To Next Week

Next week shifts to user-centered design, personas, and journey mapping.
