# Interface Playground

A frontend-only Next.js + Tailwind CSS demo for Week 06 of ICT710. The project compares five
interface types for the same doctor booking task and adds an interface-evolution timeline.

## What This Demo Shows

1. A CLI-style booking flow
2. A traditional desktop GUI
3. A touch-first mobile interface
4. A simulated voice assistant workflow
5. A simulated gesture-based interface
6. A historical timeline and comparison matrix for interface evolution

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- TypeScript

## Scope

- Frontend only
- Dummy data only
- No backend implementation

## Route Map

- `/` - Interface selector hub
- `/cli` - Command-line interface
- `/gui` - Traditional GUI
- `/touch` - Touch-optimized interface
- `/voice` - Voice user interface
- `/gesture` - Gesture-based interface
- `/timeline` - Interface evolution timeline
