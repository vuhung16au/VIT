# Interface Playground

A frontend-only Next.js + Tailwind CSS demo for Week 06 of ICT710. The project compares classic,
multimodal, spatial, adaptive, and AI-native interface types for the same doctor-booking task and
adds an interface-evolution timeline.

## What This Demo Shows

1. Classic interfaces such as CLI, GUI, and touch
2. Multimodal interfaces such as voice and gesture
3. Spatial computing that groups VR, AR, and mixed reality
4. Brain-computer and haptic interfaces for emerging accessibility and embodied interaction
5. Smart interfaces and Zero UI for predictive, sensor-driven design
6. Generative UI for AI-composed, task-specific layouts
7. A historical timeline and comparison matrix for interface evolution

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- TypeScript

## Scope

- Frontend only
- Dummy data only
- No backend implementation

## Route Map

- `/` - Interface selector hub
- `/cli` - Command-line interface
- `/gui` - Traditional GUI
- `/touch` - Touch-optimized interface
- `/voice` - Voice user interface
- `/gesture` - Gesture-based interface
- `/spatial` - Spatial computing with VR / AR / mixed reality
- `/bci` - Brain-computer interface overview
- `/haptics` - Mid-air haptics and tactile feedback
- `/smart` - Smart interfaces and Zero UI
- `/generative` - Generative UI and liquid interfaces
