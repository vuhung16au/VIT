# Context Analysis

## Elderly users at home

- Best fit: voice plus large touch controls
- Why: lower dexterity demands, conversational model, large visual targets

## Busy professional in a car

- Best fit: voice-first
- Why: hands-free and eyes-free interaction is essential

## Tech-savvy user at a desk

- Best fit: GUI with optional shortcuts
- Why: discoverability plus efficient navigation for repeat tasks
