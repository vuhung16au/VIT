# Interface Comparison

## Summary

- CLI is efficient but requires prior knowledge.
- GUI is highly discoverable and familiar for desktop users.
- Touch works well on mobile when targets are large and direct.
- Voice supports hands-free interaction but needs privacy awareness.
- Gesture is useful in special contexts but can be tiring and unclear.

## Main lesson

There is no universally best interface type. Good choices depend on task, context, user ability,
and environment.
