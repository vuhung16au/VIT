# Quickstart

## Prerequisites

- Node.js 20+
- npm 10+

## Install

```bash
cd Week07/persona-first
npm install
```

## Run Development Server

```bash
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000)

The dev server uses `--webpack --hostname 127.0.0.1` to keep local behavior consistent with the
build setup in this workspace.

## Build Production Bundle

```bash
npm run build
npm run start
```

## Lint

```bash
npm run lint
```
