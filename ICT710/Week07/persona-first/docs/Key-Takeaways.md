# Key Takeaways

This project reinforces several IxD, UI, and UX lessons:

- Designing for specific users creates more useful interfaces than designing for everyone at once.
- Persona goals should directly influence features, layout, and interaction style.
- Accessibility is part of user-centered design, not a separate add-on.
- Journey maps reveal emotional and practical friction across the full experience.
- Usability guidelines help translate persona needs into concrete design improvements.
