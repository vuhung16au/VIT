# Question Bank

## Questionnaire prompts

1. How satisfied were you with the booking experience?
2. How clear was each step?
3. Did the experience feel trustworthy?
4. Which part of the process was hardest?
5. What should we improve next?

## Interview prompts

1. What did you expect before starting the booking flow?
2. Which step felt slow or confusing?
3. What made you trust or distrust the interface?
4. If you could change one thing, what would it be?
5. Would you use this again in a real healthcare context?
