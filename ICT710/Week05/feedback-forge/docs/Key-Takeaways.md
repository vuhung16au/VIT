# Key Takeaways

This project reinforces several IxD, UI, and UX lessons:

- Different data gathering methods reveal different parts of the user experience.
- Questionnaires provide fast quantitative patterns, while interviews add context and depth.
- Observation helps teams see what users actually do, not just what they say they did.
- Triangulating multiple sources leads to stronger, more reliable design insights.
- Privacy and informed consent are part of good UX research practice, not optional extras.
