# Week 05

## Week Overview

Week 05 introduces data gathering methods such as questionnaires, interviews, and observation.

## Quick Recap From Previous Week

Week 04 applied the design process to build and compare booking app versions.

## Learning Objectives And Outcomes

Students should be able to collect useful feedback, understand triangulation, and turn raw user data into design insights.

## What To Do This Week

Read `demo-plan.md`, review the feedback collection components, and study how the app supports surveys, interviews, and observation-style evidence.

## Key Deliverable Or Takeaway

A practical understanding of how design decisions should be informed by evidence rather than assumptions.

## Looking Ahead To Next Week

Next week explores multiple interface types for the same task.
