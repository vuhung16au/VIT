# Week 11

## Week Overview

Week 11 focuses on evaluating design quality without direct user involvement first.

## Quick Recap From Previous Week

Week 10 built design language foundations and reusable interface systems.

## Learning Objectives And Outcomes

Students should be able to use heuristic evaluation, cognitive walkthroughs, analytics, and checklists to identify and prioritize usability issues.

## What To Do This Week

Read `demo-plan.md`, review the evaluation toolkit, and compare how different inspection methods reveal different kinds of design problems.

## Key Deliverable Or Takeaway

A practical framework for reviewing interfaces systematically before running formal user studies.

## Looking Ahead To Next Week

Next week moves into moderated usability testing with real users.
