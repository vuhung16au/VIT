# Key Takeaways

This project teaches several important UX lessons:

- Visual hierarchy influences where users look first and how quickly they understand a screen.
- Recognition-based design reduces memory burden and helps users make decisions faster.
- Progressive disclosure prevents cognitive overload by revealing information step by step.
- Trust is essential in healthcare interfaces and is shaped by credentials, reviews, tone, and transparency.
- Social UX matters because healthcare tasks are often completed for or with other people.
- A/B testing provides a practical way to compare design choices using measurable behavior.
