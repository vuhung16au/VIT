# Prioritization Guide

The Week 08 demo uses the MoSCoW method:

- Must Have: essential for MVP success
- Should Have: important, but the product can still function without it
- Could Have: useful enhancement if time permits
- Won't Have: deliberately excluded from the current release

## Questions to ask

- Does this requirement directly support a critical user goal?
- What is the risk if it is not delivered?
- How much effort is needed compared with the value created?
- Is this required for accessibility, trust, or operational safety?
