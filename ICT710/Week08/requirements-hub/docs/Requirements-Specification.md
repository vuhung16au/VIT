# Requirements Specification

## Purpose

This document captures the core requirements for the Week 08 doctor booking demo and shows how
persona needs become design and delivery decisions.

## Scope

- Search for doctors
- View availability
- Book and cancel appointments
- Book for family members
- Receive reminders
- Support accessible and reliable interactions

## Functional requirement examples

- FR-001 Search doctors by specialty
- FR-002 Display real-time availability
- FR-003 Send booking confirmation
- FR-006 Book for family members
- FR-010 Provide appointment reminders

## Non-functional requirement examples

- NFR-U1 Booking completed within 5 minutes for new users
- NFR-U2 WCAG 2.1 AA accessibility
- NFR-P1 Initial page load under 2 seconds
- NFR-S1 Patient data encrypted in transit and at rest

## Traceability principle

Each requirement should link to at least one persona need, one user story, and one design or
product feature so the team can explain why it exists.
