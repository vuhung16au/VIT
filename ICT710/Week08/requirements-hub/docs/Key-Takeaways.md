# Key Takeaways

This project reinforces several IxD, UI, and UX lessons:

- Requirements should be grounded in user goals, not guessed from features alone.
- Functional and non-functional requirements both shape interface decisions.
- User stories become more useful when they connect to personas and acceptance criteria.
- Environmental context changes what good interaction design looks like in practice.
- Prioritization helps teams protect core user value while keeping scope realistic.
