# User Story Template

Use the standard structure:

`As a [persona], I want to [action], so that [benefit].`

## Checklist

- Name the persona clearly
- Focus on one goal or task
- Describe the benefit from the user's perspective
- Add measurable acceptance criteria

## Acceptance criteria starter

- Given ...
- When ...
- Then ...

## Example

As Robert, I want larger text and one step at a time, so that I can book without confusion.
