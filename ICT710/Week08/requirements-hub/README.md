# Requirements Hub

`requirements-hub` is the Week 08 ICT710 demo project for Requirements Engineering. It turns user
research and personas into structured requirements, user stories, use cases, traceability views,
and a MoSCoW prioritization board for the doctor booking app.

## What this project demonstrates

1. Functional requirements for the booking domain
2. Non-functional requirements across usability, performance, reliability, and security
3. Persona-driven user stories with acceptance criteria
4. Interactive use case exploration
5. Environmental requirements that shape design decisions
6. Traceability from requirement to story to feature
7. Prioritization of scope into MVP, later releases, and out-of-scope items

## Tech stack

- Next.js 16 with the App Router
- TypeScript
- Bootstrap 5.3.3 styling via CDN import
- Tailwind CSS 4 utilities for lightweight layout styling

## Route map

- `/` - Week 08 landing page
- `/requirements` - Requirements dashboard
- `/requirements/functional` - Functional requirements explorer
- `/requirements/non-functional` - Non-functional requirements explorer
- `/requirements/user-stories` - User stories and acceptance criteria
- `/requirements/use-cases` - Use case diagram and flows
- `/requirements/environment` - Environmental requirements
- `/traceability` - Requirement traceability matrix
- `/prioritization` - MoSCoW prioritization board and roadmap
