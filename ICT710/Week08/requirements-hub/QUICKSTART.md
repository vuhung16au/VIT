# Quickstart

## Prerequisites

- Node.js 20+
- npm 10+

## Install

```bash
cd Week08/requirements-hub
npm install
```

## Run Development Server

```bash
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000)

## Build Production Bundle

```bash
npm run build
npm run start
```

## Lint

```bash
npm run lint
```
