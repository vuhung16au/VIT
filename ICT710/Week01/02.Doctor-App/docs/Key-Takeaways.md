# Key Takeaways

This project helped reinforce a few core lessons about Interaction Design, UI, and UX:

- Clear calls to action make it easier for users to understand what to do next.
- Visual feedback such as hover states, focus states, and button press effects improves confidence during interaction.
- Good spacing, hierarchy, and card-based layout make healthcare interfaces easier to scan.
- Simple search interactions with live feedback reduce uncertainty and support recognition over recall.
- Even a basic homepage can demonstrate IxD principles like motion, time, and responsiveness when feedback is immediate and intentional.
