# Week 01

## Week Overview

Week 01 introduces Interaction Design fundamentals through a simple doctor booking interface.

## Quick Recap From Previous Week

Week 00 focused on setup, tooling, and the first small IxD app.

## Learning Objectives And Outcomes

Students should be able to explain the difference between UI, UX, and IxD, identify basic IxD components, and build a simple interactive homepage with clear feedback.

## What To Do This Week

Read `demo-plan.md`, review the week materials, and explore the implemented doctor app to see how basic IxD ideas appear in a working interface.

## Key Deliverable Or Takeaway

A first interactive healthcare-style interface that demonstrates navigation, hierarchy, and visible feedback.

## Looking Ahead To Next Week

Next week focuses on problem space, interaction types, and conceptual thinking before coding.
