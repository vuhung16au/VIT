## Introduction

Welcome to the course materials for **ITSU1001: Introduction to Computer Systems and Networking**. This repository contains the lecture notes, tutorial activities, reference sheets, and assignments for the unit. 

The primary goal of this course is to introduce the idea of a computer as a system rather than just a standalone device. Students will explore hardware, software, data, communications, and how these components are interconnected in modern computer systems and networks.

## Course Contents (Sessions 01-12)

The unit is structured into 12 sessions. Here is a brief overview of what each session covers:

- **Session 01: Computers and Systems** - Explores the input-process-output-storage model and introduces the major parts of a computer system.
- **Session 02: Introduction to Systems Concepts and Systems Architecture** - Discusses what a system is, decomposition, models, and architectures like client-server and peer-to-peer.
- **Session 03: Data Formats** - Covers how data is represented, formatted, and stored in computer systems.
- **Session 04: The CPU and Memory (Part 1)** - An introduction to the central processing unit, the ALU, and the memory hierarchy.
- **Session 05: The CPU and Memory (Part 2 - Fetch & Execute Cycle)** - Deep dives into how the CPU fetches, decodes, and executes instructions.
- **Session 06: Buses, Registers and CPU Instructions** - Examines the internal communication of a computer system and the specifics of instruction processing.
- **Session 07: Computer Peripherals** - Looks at external hardware, input/output devices, and how they interface with the system.
- **Session 08: Modern Computer Systems** - Compares legacy mainframe architectures with modern computing hardware systems.
- **Session 09: Operating Systems: An Overview** - Introduces the role of the operating system in managing hardware and software resources.
- **Session 10: Networks and Data Communications (Part 1)** - Foundations of networking, network topologies, and basic data communication principles.
- **Session 11: Networks and Data Communications (Part 2)** - Advanced networking concepts, including the OSI model, TCP/IP, protocols, and ports.
- **Session 12: Cloud Computing – An Introduction** - Explores modern cloud infrastructures (SaaS, IaaS, PaaS) and web application deployment.
